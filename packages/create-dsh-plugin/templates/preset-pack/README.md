# {{PKG_NAME}}

> A DeepSeek Harness **preset pack** generated by [`create-dsh-plugin`](https://www.npmjs.com/package/create-dsh-plugin).
> 由 create-dsh-plugin 生成的 DeepSeek Harness **预设包插件**。

## What you get / 结构

```
presets/example-preset/   preset.yml（名称/描述/排序）+ agent.cordis.yml（人设 + 工具组合）
src/index.ts              HOST half — /{{PLUGIN_ID}}/list · apply · remove 路由
lib/client.js             BROWSER half — settings.section 列表面板（一键应用/移除）
```

- 预设 = `presets/<id>/` 目录：`preset.yml` 显示元数据 + `agent.cordis.yml` 组合。
- 应用 = 宿主把目录拷贝到 `<dshHome>/.agent-presets/<id>/`；官方 agent-presets
  实时发现该目录，**无需重启**，Settings → Agent presets 立即可选。
- 把你的人设写进 `presets/<id>/agent.cordis.yml` 的 persona 块即可，面板自动列出。

## Quick start / 快速开始

```sh
pnpm install
pnpm run build                 # tsc → dist/index.js

# From the PARENT directory:
dsh plugin --profile my-profile add ./{{PKG_NAME}}
dsh --profile my-profile       # web UI → Settings → {{PLUGIN_ID}} 预设 → 一键应用
# 然后 Settings → Agent presets 选择刚应用的预设
```

## Verify / 验证

dsh --profile my-profile --dump-config | grep {{PLUGIN_ID}}   # 插件行在

## Pitfalls / 坑

1. `preset.yml` 的 `name` 会直接显示在官方 Agent presets 选择器里——用中文名
   请写清楚，别用内部 id。
2. `agent.cordis.yml` 里 `{{model}}` / `{{cwd}}` 是宿主占位符，**不要替换**成
   字面量。
3. 预设行只加人设真正用到的工具（工具越少，上下文越省、越不容易跑偏）。
4. 应用写的是用户预设根（.agent-presets/），卸载插件不会自动移除已应用的
   预设——用户可在面板点「移除」或手动删目录。
