# {{PKG_NAME}}

> A DeepSeek Harness **tool with a Web UI card** generated by [`create-dsh-plugin`](https://www.npmjs.com/package/create-dsh-plugin).
> 由 create-dsh-plugin 生成的 DeepSeek Harness **带 UI 卡片的工具插件**（experimental）。

Registers the `{{TOOL_NAME}}` tool and renders its call/result as a **diff card** via
`presentCall` / `presentResult` (the tool-side Web UI extension point).

> ⚠️ experimental: this demonstrates the *tool card* render intent. A full custom Chat node
> (`ConversationNodeDefinition`) is a separate, more involved extension — see
> `docs/cookbook/adding-a-conversation-node.md` in the harness repo.

## Quick start / 快速开始

```sh
pnpm install
pnpm run build                 # tsc → dist/index.js (pure ESM)

# From the PARENT directory, install into a profile and boot:
dsh plugin --profile my-profile add ./{{PKG_NAME}}
dsh --profile my-profile       # watch for: [{{PLUGIN_ID}}] registered "{{TOOL_NAME}}" (webui diff card)
```
