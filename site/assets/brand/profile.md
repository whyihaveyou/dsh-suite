### 2️⃣ 兼容性 CI（差异化卖点）

Three awesome-lists popped up within hours of DSH launching — all static, already listing broken plugins.

dsh-suite is different: a daily GitHub Action re-tests every entry against the latest DSH release, and flips the badge automatically when upstream breaks compatibility.

That's the part static lists can't do.

### 3️⃣ 脚手架（官方缺口）

DSH ships no plugin scaffolder, and "how do I migrate my existing plugin" is the top community request.

We built create-dsh-plugin:

npm create dsh-plugin
→ a working dsh.bundle + Cordis service skeleton, one command.

### 4️⃣ 目录规模 + 第一方产出

The catalog is live with 530+ curated plugins (and a watchlist that flags the tag-squatters) — each entry re-checked by CI, refreshed hourly.

And it's not just links: we maintain our own first-party plugins (plugin-notify, plugin-session-export) plus the create-dsh-plugin scaffolder.
